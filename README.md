# Juego-De-Gato
Juego de Gato en Python con Algoritmo Min Max donde tu juegas contra tu computadora
- Requisitos
```console
python3
python-tk (tkinter)
```
- Instala TK (linux)
```console
sudo apt install python-tk
```
- Instala Python3 y tkinter (Windows) en administrador
```console
winget install Python.Python.3.13.3
```
```console
pip install python-tk
```
- Ejecuta el archivo en una Terminal o Cmd posicionado en la ruta donde se encuentra el archivo .py
```console
python3 game.py
```
